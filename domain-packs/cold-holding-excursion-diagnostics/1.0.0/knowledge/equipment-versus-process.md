# 区分制冷设备响应与运行过程偏差

发现温度偏差后，应继续确认问题来自制冷设备本身，还是来自冷却、装载、开门或气流等运行过程。FDA Food Code 的风险检查说明明确要求在温度偏差出现时进一步区分设备失效与冷却或再加热等流程故障。

设备响应不足的典型证据组合是：温度已超过现场阈值、控制器持续要求制冷，但在规定时间内没有形成足够降温；同时存在压缩机、风机或其他部件报警会进一步加强该假设。

相反，如果长时间开门或装载结束后关闭门，温度按预期恢复，这更支持运行热负荷，而不支持持续的设备响应故障。单一温度曲线通常不足以区分两者，应补充控制器、门状态和维护检查记录。

来源：U.S. Food and Drug Administration, *FDA Food Code 2022*, Annex 5。
