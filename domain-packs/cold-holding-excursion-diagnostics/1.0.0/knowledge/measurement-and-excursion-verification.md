# 温度异常的测量与复核

冷藏调查首先需要区分产品温度、设备空间空气温度和传感器自身状态。空气温度会随开门、除霜和送回风循环较快波动，不能在没有产品测量的情况下直接代表产品内部温度。

FDA Food Code 2022 的风险检查说明强调，应使用适合用途的接触式测温设备检查冷藏食品；只测表面或包间空气可能遗漏产品内部问题。固定记录器出现偏差时，应核对测量位置，并使用已校准的独立探头复测。多个位置的一致结果比单个传感器尖峰更能说明冷藏单元存在真实异常。

ReasonWeave 因此把独立产品探头确认作为“测量系统异常”的反证，把参考探头差异、过期校准和孤立尖峰作为测量问题的支持证据。这些关系只用于调查排序，不替代辖区要求的正式检查或食品处置程序。

来源：U.S. Food and Drug Administration, *FDA Food Code 2022*, Annex 5，2023-01-18 版本。
