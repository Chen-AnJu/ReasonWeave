# Support

ReasonWeave is an open-source preview maintained through the public repository.

- Use [GitHub Issues](https://github.com/Chen-AnJu/ReasonWeave/issues) for reproducible bugs and focused feature requests.
- Use the Domain Pack proposal template for new industries, predicates, rules, or attributed knowledge.
- Read [docs/troubleshooting.md](docs/troubleshooting.md) before reporting startup, model, port, or index-readiness problems.
- Do not post secrets, production evidence, kubeconfig files, raw telemetry, or private infrastructure details.

Security issues must follow [SECURITY.md](SECURITY.md) and must not be filed as public issues. The project does not currently offer paid support, a service-level agreement, or private deployment assistance.
